# Requesting a Canvas Course

**[Download the Word doc ↓](../../data/documents/AIBHS_Faculty_Canvas_Resource_Instructions.docx)**

To create a new Canvas course, instructors will need to submit a request. The link
below offers resources for requesting both registrar and non-registrar courses.
Registrar courses are tied to a course being taught, while non-registrar courses may
be used as a sandbox to experiment with Canvas or try new tools.

- [Request Canvas Shell](https://drive.google.com/file/d/1YFQwgdYzGJyZ2R1MqYC0AGtIJCoVXNS-/view?usp=sharing) (Request_Canvas_Shell.pdf, Google Drive)
- <https://elearning.ufl.edu/instructor-help/instructor-course-request/course-request-process/>
