# External Tools

The tools below are the ones AIBHS courses actually use. UF integrates many more LTI tools with
Canvas — browse the full, current list on the [UF Teaching & Learning Tool Finder](https://elearning.ufl.edu/instructor-help/teaching-and-learning-tools/tool-finder/).

## Course Communication

### EdStream

A Canvas messaging app instructors use for handling assignment-extension and re-grade requests
from students.

<https://edstream.io/>

## Automated Grading

### Kaizen

Kaizen is an automated feedback and grading tool in Canvas.

[Tutorial: How to set up Kaizen in Canvas](https://mediasite.video.ufl.edu/Mediasite/Play/b5b9a76d445746bead9c809d3d675be71d)

### Gradescope

Efficient exam and assignment grading with auto-grading, rubrics, and feedback tools.

<https://guides.gradescope.com/hc/en-us/articles/23586543164173-Using-Gradescope-LTI-1-3-with-Canvas-as-an-instructor>

## Proctoring

### Honorlock

AI-powered virtual proctoring service for online exams.

<https://pfs.tnt.aa.ufl.edu/teaching-and-technology-resources/online-proctoring/honorlock-instructor-guide/>

## Accessibility

### Ally Accessibility Report

Scans course content for accessibility issues and gives students alternative formats of course
files.

<https://www.uhd.edu/computing/training-lms/ally-accessibility-report-in-canvas.aspx>

## Other Tools Worth Knowing About

Not currently used in an AIBHS course, but commonly requested and already integrated with UF
Canvas. Full details on the [Tool Finder](https://elearning.ufl.edu/instructor-help/teaching-and-learning-tools/tool-finder/).

| Tool | Category | What it does |
|---|---|---|
| Turnitin | Plagiarism Detection | Compares submitted work against a database to detect plagiarism |
| Ed Discussion | Collaboration | Team discussion tool that supports code and math snippets |
| Piazza | Discussion | Q&A platform for class discussions and collaboration |
| H5P | Content Creation | Interactive content creation with gradebook integration |
| Mentimeter | Interactivity | Real-time interactive presentations and polling |
| Top Hat | Assessment | Interactive in-class quizzing and polling |
| Kaltura / Mediasite | Content Creation | Lecture recording and video hosting with interactive knowledge checks |
| My Learning Analytics | Analytics | Student performance and progress dashboard |
| UDOIT | Accessibility | Scans a course for accessibility issues |
| NaviGator AI Suite | AI/Analytics | UF-developed generative AI tools for teaching and learning |
